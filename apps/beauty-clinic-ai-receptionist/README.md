# AI音声受付デモ（美容クリニック向け）

海外AI事例DBの採用事例「[匿名の複数拠点美容クリニック（米国／Flipbytes）－老朽化した予約システムをAPIハックしてAI音声受付を24時間化](https://www.flipbytes.com/blog/case-study-ai-voice-receptionist-handles-calls-and-booking-for-a-multi-location-cosmetic-clinic/)」を元にした、業種別デモWebアプリです。

クリニック名・登場人物・数値はすべて架空のものです。

## 想定ペルソナ

- **ペルソナA：来院希望の患者様** — 視覚的な安心感・信頼を重視。AI受付とのやり取りを疑似体験できるチャットデモを中心に構成。
- **ペルソナB：受付・カウンセラースタッフ** — 業務のスピード感を重視。今日の対応件数やエスカレーション対応など、合間にサッと確認できるダッシュボードを構成。

画面上部のタブでペルソナ表示を切り替えられます。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド不要・外部依存なし）。

## 元になった事例のポイント

- 拠点拡大に伴い電話対応が追いつかず、繁忙時間帯や夜間・週末の取りこぼしが課題だった
- 老朽化した予約システムのAPIをリバースエンジニアリングし、AI音声受付と接続
- AIは新規予約・変更・キャンセル・空き状況案内まで完結、複雑・機微な内容のみ人へエスカレーション
