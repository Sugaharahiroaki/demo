# demo

海外AI活用事例DBで「採用」となった事例をもとに、業種別のペルソナ2種類（意思決定者/経営層 と 現場スタッフ）に向けたデモWebアプリを自動生成していくリポジトリです。

各事例は `apps/<slug>/` 以下に、単独で開けるビルド不要の静的Webアプリとして格納されます。
